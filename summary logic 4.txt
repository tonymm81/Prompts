4.11 Summary optio pitää logittaa, jotta voin seurata, onnistuuko vai epäonnistuuko yhteenvedon luonti.

4.12 Kun yhteenvetoa eli summarisointia tehdään qwen agentilla sen summarisoinnin json rungon ja promptin pitää näyttää tältä:
[Do not repeat the input.
Do not reconstruct the input structure.
Do not include any other fields.
Do not echo the code block.
Output must be valid JSON with exactly these two fields.

Json input:
{
  "task": {
    "instruction": "Generate two summaries: (1) user_intent: summarize the user's question in max 10 words. (2) llm_summary: summarize the model's answer in max 10 words. Do not repeat or quote the input."
  },
  "input": {
    "user_prompt": "Tähän kenttään käyttäjältä tullut prompti",
    "llm_response": "Tähän tulee Lmm mallin vastaus, joka saatiin generate funktion lopussa {result} kirjastosta"
  },
  "meta": {
    "req_id": "Tämän voi ottaa muuttujasta {request_id} mikäli se on järkevää. Jos summarisointi vaatii oman id:n luo sellainen",
    "conversation_title": "Tämä otsikko tulee ui:sta eli {conversation_title} muuttujasta",
    "model": "qwen2.5",
    "notes": "Separate intent and semantic summaries to avoid echoing."
  }
}] Tee tähän myös time out käsittely vaikkapa 3 minuutille ja silloin ohjelma ei odota enää eikä tallenna kantaan mitään.
